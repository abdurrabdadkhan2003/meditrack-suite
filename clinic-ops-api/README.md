# Clinic Ops API (`clinic-ops-api`)

RESTful API backend for Checklife Health Care Services. Built with FastAPI, SQLAlchemy, and Pydantic. Features JWT authentication, role-based access control, and complete CRUD operations for patients, appointments, and billing data.
